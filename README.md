## Публикация

Загрузите **всё содержимое нового архива** в корень существующего репозитория. Вместе с `index.html` обязательно нужны новые `portfolio.css`, `portfolio.js`, `favicon.svg` и изображение статистики в `assets/`.

Сохраняйте `CNAME` и `.nojekyll`. GitHub Pages использует ветку `main`, каталог `/ (root)`. Настройки домена менять не требуется.

Старые PDF-резюме, космический фон и прежняя обложка сохранены в рабочей папке, но новая страница на них не ссылается. Архив содержит только необходимые файлы. Подготовка архива не публикует изменения автоматически.
