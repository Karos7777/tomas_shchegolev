# Tomas Shchegolev — Portfolio

Статический сайт портфолио для GitHub Pages.

Сайт: [https://karos7777.github.io/tomas_shchegolev/](https://karos7777.github.io/tomas_shchegolev/)

Репозиторий: [https://github.com/Karos7777/tomas_shchegolev](https://github.com/Karos7777/tomas_shchegolev)

## Как залить на GitHub

1. Открой репозиторий [Karos7777/tomas_shchegolev](https://github.com/Karos7777/tomas_shchegolev).
2. Залей **все файлы из этого архива** в корень репозитория (замени старые `index.html` и `assets`).
   - Через сайт GitHub: **Add file → Upload files** — перетащи папки `assets`, `index.html`, `favicon.svg`, `.nojekyll`.
   - Или через GitHub Desktop / git: скопируй файлы в клон репозитория и сделай commit + push.
3. Включи GitHub Pages:
   - **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**, folder: **/ (root)**
   - Save
4. Через 1–2 минуты сайт откроется по адресу  
   `https://karos7777.github.io/tomas_shchegolev/`

Ничего собирать не нужно: это обычный HTML + картинки + видео.

## Как добавить скрытый спойлер

В `index.html` найди секцию `id="hidden"`. Скопируй готовый блок `<details class="spoiler">...</details>` и вставь рядом. Внутри можно писать текст, ссылку или ещё одно видео.
